# Zúrich en Navidad 2026

Guía personal en español para la visita del 20 al 27 de noviembre de 2026.
Online: https://mikefaehch.github.io/zuerich/

- `data.js` – todos los contenidos (lugares, ideas, favoritos, configuración)
- `app.js` – lógica · `style.css` – diseño · `index.html` – estructura y metadatos
- `img/` – fotos WebP · `vendor/` – fuentes (OFL) y Leaflet · `sw.js` – modo sin conexión
- `tests/check.py` – comprobación completa: `python3 tests/check.py`

Para trabajar con Claude: ver `CLAUDE.md`. Publicación: commit en `main`, GitHub Pages lo publica solo.
